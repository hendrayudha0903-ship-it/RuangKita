# AI Usage - RuangKita

## 1. Penggunaan AI

AI digunakan sebagai alat bantu selama proses pengembangan aplikasi Flutter RuangKita.

AI membantu dalam:
- Membantu memahami instruksi tugas.
- Membantu menyusun struktur kode Flutter.
- Membantu memperbaiki error pada kode.
- Membantu membuat fungsi tampilan kartu ruangan.
- Membantu membuat fitur filter berdasarkan status ruangan.
- Membantu membuat tampilan detail ruangan menggunakan Bottom Sheet.
- Membantu memahami penerapan responsive layout.
- Membantu melakukan pengecekan dan debugging project.

## 2. Contoh Prompt

Beberapa contoh prompt yang digunakan:

> "Bantu saya membuat dashboard Flutter untuk menampilkan daftar ruangan laboratorium."

> "Kenapa muncul error _buildRoomCard dan bagaimana cara memperbaikinya?"

> "Buatkan filter ChoiceChip berdasarkan status ruangan."

> "Buatkan detail ruangan yang muncul ketika card diklik."

> "Bantu membuat layout Flutter yang responsive untuk berbagai ukuran layar."

## 3. Peran AI

AI digunakan sebagai alat bantu dalam proses pengembangan. 
Kode yang diberikan AI kemudian dipahami, diterapkan, diuji, dan disesuaikan dengan kebutuhan project RuangKita.

## 4. Pengujian

Setelah menerapkan bantuan AI, aplikasi diuji menggunakan Flutter untuk memastikan fitur dapat berjalan dengan baik.
